# 0. How to Use This Bible

- **Before bootstrapping** any Dart/Flutter project: read it.
- **Before reviewing** any Dart/Flutter code: read it.
- **When an agent is assigned** Dart/Flutter work: the `dart-clean-architecture` skill loads first and points here. If it doesn't, load this doc anyway.
- The bible is ~2/3 Dart doctrine, ~1/3 Flutter. The Dart doctrine is the foundation; Flutter is just the outermost ring of the same bulls-eye.
